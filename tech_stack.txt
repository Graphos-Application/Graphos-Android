GalleryAI1 - 사용 기술 스택 정리 (2026-09-17 기준)
========================================================

■ 플랫폼 / 빌드
- Android (Kotlin), minSdk 26 / targetSdk·compileSdk 37
- AGP (Android Gradle Plugin) 9.1.1
- KSP (Kotlin Symbol Processing) 2.2.10-2.0.2
- APK 아키텍처: arm64-v8a, x86_64만 포함 (32비트 제외, 용량 절감)

■ AI 추론 엔진
- ONNX Runtime Mobile (onnxruntime-android 1.22.0)
  - MobileCLIP (vision_model.onnx + text_model.onnx): 이미지-텍스트 임베딩 기반
    자동 태깅 및 검색어 매칭의 핵심 엔진. 완전 로컬 추론(CPU), 기기별 서버
    승인(AICore/Gemini Nano) 불필요.
  - 자체 구현 CLIP 토크나이저(Kotlin, BPE 방식) - clip_vocab.txt, clip_merges.txt
  - YOLO11n.onnx: COCO 80종 객체 탐지 하이브리드 보강(MobileCLIP이 약한
    "사람" 등 카테고리 보완), 10MB 경량 모델
- ML Kit Translate (com.google.mlkit:translate 17.0.3)
  - 한국어 검색어 <-> 영문 태그/임베딩 매칭용 번역
  - 벡터 검색(Tier2) 시 한글 질의를 영문으로 번역 후 임베딩 비교 (한글 문장
    유사도 오작동 버그 수정에 사용)

■ 데이터 저장
- Room (androidx.room 2.8.4): PhotoAlbum / TagMaster / PhotoTagMap 3테이블 구조
  (기존 SharedPreferences JSON 저장 방식 대체)

■ UI (XML 레이아웃 기반, Compose 미사용 - 과거 제거됨)
- AndroidX AppCompat 1.7.0
- ConstraintLayout 2.1.4
- RecyclerView 1.3.2
- CardView 1.0.0
- ViewPager2 1.1.0
- Glide 4.16.0 (이미지 로딩)
- PhotoView 2.3.0 (핀치줌 이미지 뷰어)
- AndroidX Lifecycle Runtime KTX 2.10.0
- AndroidX Core KTX 1.19.0

■ 테스트
- JUnit 4.13.2, AndroidX JUnit 1.3.0, Espresso Core 3.7.0

■ 아키텍처 요약
- AutoTagger/PreciseTagger/AiCaptioner/AiPromptTagger/FaceTagger 등 4~6단
  ML Kit 폴백 체인을 MobileCLIP+Room 단일 구조로 전면 교체 (2026-09-05)
- MobileCLIP(전역 임베딩) + YOLO11n(객체 탐지) 하이브리드 태깅으로 정확도 보강
- 검색 파이프라인: 태그 매칭(Tier1) + CLIP 벡터 검색(Tier2, 한글 질의는
  ML Kit 번역 후 비교)
- 씨앗 사전(seed_tags.json) 192개 태그로 확장
