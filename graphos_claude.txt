2. ONNX Runtime — "AI 모델을 폰 안에서 돌리는 엔진"
--------------------------------------------------
- AI 모델(딥러닝 신경망)을 학습시키는 건 보통 파이썬으로 하지만,
  그렇게 만든 모델을 실제 서비스에서 "실행"만 할 때는 더 가볍고 빠른
  전용 엔진이 필요해요. ONNX Runtime이 그 역할이에요.
- ONNX는 파이썬(PyTorch 등)에서 학습한 모델을 안드로이드에서도 돌릴 수
  있게 변환한 표준 파일 형식(.onnx)이라고 생각하면 됩니다.
- 이 앱에서는 서버(클라우드 AI, 예: ChatGPT처럼 인터넷에 물어보는 방식)를
  전혀 쓰지 않고, 폰 안에서 전부 계산(로컬 추론)해요. 인터넷 연결 없이도
  동작하고, 사진이 외부로 안 나간다는 장점이 있어요.
- CPU로 실행돼요(그래픽카드용 GPU 가속은 안 씀).

  2-1. MobileCLIP 모델
  - "사진"과 "글자(설명)"를 같은 좌표 공간에 숫자 벡터로 변환해주는
    AI예요. 예를 들어 "강아지 사진"과 "강아지"라는 단어를 벡터로
    바꾸면 그 두 벡터가 서로 가깝게 나와요.
  - 이 원리로 사진마다 어울리는 태그(예: 강아지, 바다, 음식)를 자동으로
    붙이고, 나중에 검색어를 벡터로 바꿔서 비슷한 사진을 찾아줘요.
  - 비전(사진 이해) 모델과 텍스트(글자 이해) 모델 2개가 세트로 있어요.
  - 원래 영어 기반 모델이라, 영어 문장을 벡터로 바꾸는 "토크나이저"
    (문장을 AI가 이해하는 숫자 단위로 쪼개는 전처리기)를 Kotlin으로
    직접 구현했어요.

  2-2. YOLO11n 모델
  - "사진 속에 어떤 물체가 어디에 있는지" 박스를 그려서 찾아주는
    객체 탐지(Object Detection) AI예요. (YOLO = You Only Look Once)
  - 사람 80종류의 흔한 사물(COCO라는 표준 데이터셋 기준: 사람, 자동차,
    강아지, 가방 등)을 잘 찾아요.
  - MobileCLIP 혼자서는 "사람"처럼 흔한 대상을 놓치는 경우가 있어서,
    이 모델을 보조로 같이 돌려서 정확도를 보강했어요(하이브리드 방식).
  - 모델 파일이 10MB밖에 안 될 정도로 가벼워요.


3. ML Kit Translate — "번역기"
-------------------------------
- 구글이 만든 온디바이스(폰 안에서 도는) 번역 라이브러리예요.
- MobileCLIP은 원래 영어를 이해하는 모델이라, 사용자가 한국어로
  "바다 사진 찾아줘"라고 검색하면 이걸 영어로 번역한 다음 AI에게
  넘겨야 정확하게 동작해요.
- 실제로 이 프로젝트에서 번역을 연결 안 했을 때 한국어 문장끼리
  검색이 다 비슷하게 나오는(구분이 안 되는) 버그가 있었는데, 번역을
  거치게 고치니 정상 동작했어요.


4. Room — "앱 안의 미니 데이터베이스"
--------------------------------------
- 안드로이드 앱 안에서 SQL 데이터베이스(SQLite)를 쉽게 쓰게 도와주는
  라이브러리예요. 학교에서 배우는 관계형 데이터베이스(테이블, 기본키,
  외래키)를 폰 안에 그대로 만드는 거라고 보면 됩니다.
- 이 앱은 3개 테이블을 써요:
  - PhotoAlbum: 사진 정보
  - TagMaster: 태그 종류 목록
  - PhotoTagMap: 어떤 사진에 어떤 태그가 붙었는지 연결(다대다 관계)
- 예전에는 이런 정보를 SharedPreferences(설정값 저장용, JSON 텍스트로
  욱여넣는 방식)에 저장했는데, 데이터가 많아지니 비효율적이라 정식
  데이터베이스인 Room으로 바꿨어요.
